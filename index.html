Ocean Scan

Read-only scanner for the Fisker Ocean with a vLinker FD+. It never clears codes, resets modules or writes anything.

2 · Run a check

Scans

Full scan reads part numbers, software versions and every fault code, including stored ones. Fault details then reads the conditions saved with each code it found (needs a scan first).

Car readings

Car's own 12V compares what the car thinks its 12V is with what the vLinker measures. A big gap points at the battery sensor (IBS). Listen test sends nothing.

Advanced (read-only)

Discovery asks the chosen module for every data ID in the range, one at a time, and lists the ones it answers. Up to 1,024 IDs per run, about 4 per second. It stops by itself if the 12V drops below 11.8 V. Good ranges to try: F180–F1FF (identification), then 0100–01FF, DD00–DDFF, then wider.

USB CAN adapter (listen-only)

For a CANable-type adapter plugged into this phone or tablet's USB-C port (OTG adapter if needed), wired to the car as in the CAN adapter guide. It only listens: the adapter is opened in listen-only mode, so it never sends anything, not even acknowledgements. Chrome on Android only.

Not connected

Works with candleLight firmware (shows as gs_usb) and slcan firmware. Nothing is sent on the car's network.
